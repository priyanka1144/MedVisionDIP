Applied Techniques

01

Laplacian Sharpening

Second-order derivative filter to enhance fine structural detail in medical imagery.

[ 0, -1, 0]
[-1, 4, -1]
[ 0, -1, 0]
02

Sobel Edge Detection

Gradient-based operator computing Gx and Gy to find anatomical boundaries.

Gx: [-1,0,1;-2,0,2;-1,0,1]
Gy: [1,2,1;0,0,0;-1,-2,-1]
03

5×5 Averaging Filter

Spatial domain low-pass filter for noise suppression before mask creation.

1/25 × ones(5×5)
04

Enhancement Mask

Structural mask combining Sobel edges with smoothed image for selective boosting.

Mask = Sobel × Smoothed
05

Final Composite

Enhanced image formed by adding the structural mask back to the original.

Final = Original + Mask
06

Gamma Correction

Power-law intensity transformation for brightness and contrast tuning.

s = c · rγ
